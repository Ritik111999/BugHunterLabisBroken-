WeChirp (native shell)

When server.url is set in mobile/capacitor.config.js (from your repo root .env APP_URL + /app), this file is not shown — the WebView loads your Laravel app from that URL (same origin as the WeChirp SPA, e.g. /app).

For a purely bundled build (no live server), copy your built web assets into mobile/www and remove or clear server.url, then run npx cap sync.
